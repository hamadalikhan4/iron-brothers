# Reference review

Reference: https://lean-doze-77547019.figma.site/

Inspected on 29 September 2026 UTC. The public reference is titled “Figma Make App” and represents Iron Brothers, a mining, minerals and trading company.

## Observed design

- Forest-green identity, warm gold/copper accents, Inter typography and mountain photography.
- Fixed navigation with a mining submenu and an opportunities CTA.
- Large photographic home hero followed by statistics, company introduction, services, mine areas, minerals, trading and a partnership footer.
- Pale internal sections, image cards, dark introductory banners, filter buttons and inquiry forms.
- Public reference navigation changes views under the same URL. This implementation adds distinct shareable paths.

## Observed features and implementation

| Reference feature       | Current implementation                                        |
| ----------------------- | ------------------------------------------------------------- |
| Home and About          | Main sections recreated using reusable components             |
| Mining categories       | Seven mineral cards with inquiry context                      |
| Four mine areas         | Schematic selector and dedicated detail routes                |
| Leasing directory       | Status filters and contact form routing                       |
| Trading marketplace     | Search, category filters, quote routing                       |
| Portfolio               | Eight reference entries, filtering, project dialogs           |
| Media                   | Filterable photo gallery and lightbox; videos await real URLs |
| Team                    | Department tabs and role cards; names/photos await approval   |
| Contact                 | Inquiry validation and download draft; API integration point  |
| Social links / WhatsApp | Not linked to placeholder destinations                        |
| Privacy / Terms         | Requires client-approved content before publication           |

This is an initial recreation, not an exact exported copy. Some descriptive copy is condensed. The reference media page displays video titles/durations but no client-approved video sources were supplied; the new site does not pretend image cards are playable videos. The site explorer is deliberately identified as schematic, with no claim to cadastral accuracy.

## Content needed from the client

- Official logo files, approved company description and preferred business name.
- Verified office address, phone, WhatsApp, email and social profiles.
- Staff names, roles, bios and permissioned portraits.
- Official photographs/video URLs, project details and publication approval.
- Verified mine information, mineral assessments, lease availability and approved claims.
- Final inquiry workflow: who receives requests and whether administration, CRM or document uploads are required.
- Domain, hosting preference and approved privacy/terms content.
